# 📝 Task 02 — Array Analysis

## 📌 Assignment

This task was part of the practical coursework for the **Fundamentals of Programming** course. The purpose of the task was to practice working with arrays, loops, conditional statements, and basic data processing in C++.

### Question

Write a C++ program that inputs an **array of 10 integers** from the keyboard.

The program should calculate and print:

- The largest (maximum) number in the array.
- The smallest (minimum) number in the array.
- The sum of all numbers.
- The average of the numbers.
- The number of even values.
- The number of odd values.

## 💡 Approach

The problem was solved by:

1. Creating an array to store 10 integers.
2. Reading 10 values from the keyboard.
3. Storing each value in the array.
4. Assuming the first element is the maximum and minimum initially.
5. Comparing the remaining elements to find the largest and smallest values.
6. Calculating the sum of all elements.
7. Checking each element to determine whether it is even or odd.
8. Calculating the average of the array elements.
9. Displaying all the calculated results.
10. Testing the program using different sets of numbers.
