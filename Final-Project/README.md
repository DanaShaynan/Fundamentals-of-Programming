# 🚗 Car Cleaning System

## 📌 Project Overview

The **Car Cleaning System** was developed as the final project for the **Fundamentals of Programming** course.

The project is a menu-driven C++ application designed to manage cars and provide different vehicle-related services through a simple command-line interface.

## 🎯 Project Objectives

The main objectives of the project were:

- Practice programming fundamentals using C++.
- Apply arrays and structures to organize data.
- Use functions to divide the program into manageable parts.
- Apply loops and conditional statements.
- Implement a menu-driven system.
- Practice searching, adding, updating, and deleting data.
- Record and display performed services.

## ⚙️ Main Features

### 🚘 Car Management

The system allows the user to:

- Add a new car.
- Store the car type.
- Store the plate number.
- Store the car color.
- Display all registered cars.
- Remove a car.

### 🧼 Car Services

The system provides several services:

- Car Cleaning
- Car Charging
- Oil Change

### 📋 Service History

The system records the services performed for each car and allows the user to display the service history.

## 📝 Main Menu

The system provides a numbered menu that allows the user to select the required operation.

1. Add Car
2. Display Cars
3. Clean Car
4. Charge Car
5. Change Oil
6. Remove Car
7. Display Service History
8. Exit
