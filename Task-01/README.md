# 📝 Task 01 — Student Grade Calculator

## 📌 Assignment

This task was part of the practical coursework for the **Fundamentals of Programming** course. The purpose of the task was to practice using variables, input/output, arithmetic operations, and conditional statements in C++.

### Question

Write a C++ program that asks the user to enter the marks of three subjects. The program should calculate the student's average mark and determine the corresponding grade.

The grading system is:

- 90 - 100: A
- 80 - 89: B
- 70 - 79: C
- 60 - 69: D
- Below 60: F

## 💡 Approach

The problem was solved by:

1. Reading the marks of three subjects from the user.
2. Calculating the average of the three marks.
3. Using conditional statements to determine the corresponding grade.
4. Displaying the average mark and the grade.
5. Testing the program using different sets of marks.
6. Reviewing the results to ensure the grade was calculated correctly.
