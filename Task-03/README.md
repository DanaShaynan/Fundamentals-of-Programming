# 📝 Task 03 — Menu-Driven Calculator

## 📌 Assignment

This task was part of the practical coursework for the **Fundamentals of Programming** course. The purpose of the task was to apply functions, loops, conditional statements, and user interaction to develop a simple calculator program using C++.

### Question

Develop a C++ calculator program that allows the user to perform different arithmetic operations through a menu.

The program should provide the following options:

- Addition
- Subtraction
- Multiplication
- Division
- Exit

The program should continue displaying the menu until the user chooses the exit option. Each arithmetic operation should be implemented using a separate function.

## 💡 Approach

The problem was solved by:

1. Creating separate functions for addition, subtraction, multiplication, and division.
2. Displaying a menu containing the available operations.
3. Reading the user's choice.
4. Asking the user to enter two numbers.
5. Using a switch statement to select the requested operation.
6. Calling the appropriate function to perform the calculation.
7. Displaying the calculated result.
8. Handling division by zero to prevent an invalid calculation.
9. Repeating the menu until the user chooses to exit.
10. Testing the program with different operations and inputs.
